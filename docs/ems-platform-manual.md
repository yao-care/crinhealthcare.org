# 油水電氣資料治理平台｜操作手冊

網址：`https://ems-admin.crinhealthcare.org/p/`（手機、平板、電腦都可以用）。
舊版入口（電力健檢填報、能源盤點、看板維護）仍在 `https://ems-admin.crinhealthcare.org/`，兩邊共用登入。

## 0. 第一次使用

1. 用院所共用帳號（例：`hosp-803`）登入 `/p/`。共用帳號在平台上是該院的「院所管理者」。
2. 到「系統管理 › 帳號與權限」替每位同仁建立個人帳號，指定角色。一個人可以有多個角色。
3. 同仁第一次登入要先改密碼（至少 10 字，含英文與數字）。可在「帳號」頁啟用兩步驟驗證。
4. 之後請用個人帳號作業：裁決、核准、匯出都記在個人名下。

| 角色 | 主要畫面 | 不會有的權限 |
|---|---|---|
| 盤點承辦 | 我的工作台、標的台帳、現場盤點、來源追查、匯入 | 核准採用值 |
| 資料保管者／設備管理員 | 現場盤點、匯入、差異案件的補件 | 對報告做最終裁決 |
| 報告承辦 | 差異案件、資料集、報告案件 | 改寫原始證據 |
| 資料審核者 | 待審核採用值、資料集核准與定版 | 刪除稽核日誌 |
| 報告核准者 | 報告核准與封存 | 改寫已封存版本 |
| 管理者 | 院區與單位進度看板 | 經公開看板取得原始文件 |
| 一般同仁 | 全院公開進度、成果 | 看帳單、個資 |
| 系統管理員 | 係數、規則、模板、設定、帳號 | 代替業務判定資料正確性 |
| 稽核／查驗 | 證據鏈、報告快照、稽核日誌（唯讀） | 修改任何業務資料 |

上方的「院所」選單決定目前作業的院所；總院的授權涵蓋所屬分院。「年度」選單決定看哪一年。

## 1. 盤點承辦

**工作台**（首頁）：上方數字是「我的待辦、本期已完成、待找來源、待補件、差異案件、已被採用成果」；下方表格每列一個標的，「下一步」欄告訴你該做什麼。

**建立標的**（標的台帳 › 新增）：先選「盤點什麼」，系統只會出現需要填的欄位，名稱也自動帶好（例：分離式冷氣 3）。油類問油種、冷氣問冷媒種類、滅火器問藥劑、高壓開關問型式；電號、水號、車牌填在識別碼，同院區同類型不可重複（一物一碼）。院區、樓層、倍率、上下層、保管者都收在「進階」，不確定可以不填。

**上下層**：總表→分表、共用油槽→多台發電機，在標的詳細頁「上下層」建立。多台發電機共用一個油槽時，同一次補油只算一次。

**判定適用性**：每個標的要判定「適用／不適用／待查證」。不適用要寫原因，並由另一位審核者核准。

**找來源**（資料來源與追查）：
1. 「找線索」輸入要找的資料（柴油、冷媒、水費），系統列出常見證據、本院已有的標的與來源、去年的經驗。這些都只是候選。
2. 按「以此建立追查」。每問一次人就「記錄詢問」，對方回覆或轉介時「記錄回覆」。
3. 問不到就「移交統籌人」。
4. 找到後按「找到了」：填來源名稱、保管者；已向本人確認才勾「已確認」。系統會把怎麼找到的寫進知識庫，明年直接用。

**登錄數據**（現場盤點）：掃描標的 QR Code 或搜尋，預設只要選月份、填數字、拍照，單位自動帶入。
- 電表、水表這類累積讀值，填讀表日和表頭讀數，系統自動算用量。
- 「其他情況」裡有：帳單不是整月（照帳單填起迄）、沒有數字（選缺漏、未知或實際為零，不要填 0）、換表或歸零、單位不同、備註。
- 網路不穩時會暫存在手機，恢復連線後會請你確認再上傳；伺服器不會覆蓋既有資料。

**檔案匯入**（匯入／辨識／介接）：下載範本 → 填好 → 上傳 → 看預覽與錯誤清單 → 確認匯入。同一份檔案重送不會重複寫入；整批可撤銷（已成為採用值的不能撤）。

**電費單辨識**：上傳 PDF 或照片，系統提出辨識結果；每一格都要勾「已核對」才能寫入。

**修正**：觀測值不能覆寫。在觀測值詳細頁按「修正」並寫原因，系統建立新版本，舊版保留。

## 2. 報告承辦

**檢核**（數據品質中心 › 檢核規則與結果）：選年度執行。結果分「提示／警示／錯誤」。跨來源差異超過門檻、油槽平衡不符會自動開差異案件。帳單分攤後的比較只提示，不開案，因為分攤值不能判斷哪筆正確。

**差異案件**：指派處理人 → 調查中或「要求補件」（會建立待辦給保管者）→ 提出採用方案。不需調整時由審核者寫理由結案。

**多源比對**（標的詳細 › 概況 › 多源比對）：左邊是各來源的原始值、標準化值、計量邊界、佐證；下方是對齊到自然月後的差異；右邊是佐證檔。

**資料集**：每年建一個共用資料集。
1. 「批次帶出」：期間內只有單一來源、檢核通過、沒有差異案件的資料，一次帶出採用值草案。
2. 有多個來源或差異的，用「逐筆裁決」：選標的、指標、期間，指定採用來源；需要推估時選「衍生值」並寫方法（例：存量平衡 3800＋2000－4300）。不適用、缺漏要明示，不填 0。
3. 每筆裁決都要寫理由。高影響的（衍生值、估計、差異大於 10%、金額或用量很大）需要兩位審核者。
4. 全部核准後「送審」→ 審核者核准 → 定版。定版後不能改；要修正就「開新版本」，已引用舊版的報告不受影響。

**報告**（報告與成果 › 報告案件）：
1. 新增案件：選模板（系統依發布日期選版次，例：2027-01-01 起 GRI 改用新版）、年度、資料集、審核人、核准人。
2. 案件頁三欄：左邊章節欄位與狀態、中間數值、右邊點欄位看計算過程與佐證。上方列出缺漏。
3. 文字段落在案件頁填寫。
4. 「產製」會凍結當時的數值、係數版本、規則版本。資料集未定版時只能預覽，不能送審。
5. 送審 → 審查 → 核准並封存。封存後可匯出 XLSX、CSV、DOCX、PDF；「重現」會用封存的版本重算並比對。
6. 依官方格式人工送件後，按「記錄已人工送件」。系統沒有串接政府申報平台，匯出檔不等於已完成申報。

**溫室氣體盤查報告（ISO 14064-1:2018）**：用「組織溫室氣體盤查報告書」模板（第 2 版），章節依 9.3.1 條必要內容編排。送審前到「報告與成果 › 溫室氣體盤查設定」：
1. **院所基本資料**：組織描述、報告負責人、查證狀態等填一次，之後每年的報告自動帶入；移除量、查證狀態有預設文字。
2. **間接排放顯著性評估**：系統能估算的會先算好並建議顯著與否（需係數庫有對應係數），按「採用估算」即可；你知道會顯著的項目（例：員工通勤、醫療廢棄物）手動填，其餘按「一鍵判定不顯著」。
3. **基準年**：第一次盤查按「一鍵設定」以最早定版的年度為基準年；之後結構或方法變更用「重新計算」留紀錄。
4. 盤查邊界：每院已預設「全院（營運控制法）」，新報告案件自動帶入；有委外或租賃設施再修改。新報告案件也會自動帶入本年度已定版的資料集。
系統自動產生：依氣體分列、生質 CO₂、排除說明、量化方法與變更、係數與 GWP、不確定性（誤差傳遞法）、排放源鑑別表、數據品質評分。燃料含生質成分在標的專屬欄位填 `{"biogenicShare":0.02}`；數據品質等級可用 `{"dq":{...}}` 人工指定。

## 3. 審核者與核准者

- 「待審核採用值」列出等你核准的裁決。你提出的、或你已經核准過第一輪的，不能再審（按鈕會停用並說明）。
- 退回一定要寫理由；退回後標的進度變「退回補件」。
- 資料集「核准」與「定版」分開：核准表示內容確認，定版後才會被正式報告引用。
- 報告核准者不能是產製者或審查者。

## 4. 管理者與一般同仁

- **全院公開進度**：油水電氣四類的適用性確認率、來源定位率、資料取得率、驗證通過率、審核完成率、定版率。滑過每一列可看公式。這裡不會出現費用、電號、聯絡人或原始文件。
- **院區與單位進度**（管理者）：加上阻塞清單（保管者未知、逾期待辦、高嚴重度差異）、案件處理天數、費用彙總（需檢視敏感欄位權限）。
- **成果回饋**：「我的盤點成果與引用」列出你提供的資料被哪些報告實際採用；標的詳細頁也會顯示「這項盤點已支援 N 項成果」。

## 5. 系統管理員與院所管理者

- **帳號與權限**：建立帳號、指定角色與院所範圍；可設授權有效期間與「代理」（代理人看得到被代理人的待辦）。院所管理者只能管理本院帳號，不能授予系統管理員。
- **係數與計算規則**：系統預設係數（燃料排放係數、熱值、GWP AR5／AR6、電力排放係數、化糞池參數）一開始是「待核准」，請核對來源後由**另一位**管理員發布。每年能源署公告新的電力排放係數時，新增一筆新年度係數並發布。計算只用已發布版本。
- **門檻與設定**：差異門檻、檢核規則、高影響裁決條件、案件期限、GWP 版本、看板公開範圍、通知方式。修改流程一律「建草稿 → 送審 → 另一人發布」，可回復舊版；已封存報告不受影響。
- **報告模板**：模板與欄位映射有版本；修改要先建草稿版。
- **介接**：舊系統電費單、舊貼紙抄表、儲能櫃 ems-bridge、HTTP 拉取、檔案投遞目錄、外部推送（權杖只顯示一次）。連續失敗 5 次會停止並通知。
- **歷史資料移轉**：上傳原碳盤查表，系統保留每列原始儲存格座標，對應到盤點項目；非油水電氣項目（通勤、出差、廢棄物…）保留為參照，不塞進四大類。範疇與類別是否適用要人工確認。
- **稽核日誌**：查詢任何新增、修改、核准、退回、下載、設定變更；「驗證雜湊鏈」確認紀錄沒被竄改。
- **備份與還原**：每天台灣時間 02:00 自動備份並驗證；可手動備份、做還原演練（唯讀比對，不覆蓋現行資料）。

## 6. 稽核與查驗人員

稽核角色可讀取證據鏈（含限閱、機密佐證）、報告快照、稽核日誌與資料集定版雜湊，不能修改任何業務資料。查一個報告數字的來源：報告版本頁 → 欄位 → 計算展開（採用值、係數版本、公式）→ 資料集 → 裁決（誰、何時、理由）→ 原始觀測 → 佐證檔（雜湊）。

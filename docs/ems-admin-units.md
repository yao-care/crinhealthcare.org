1. **7 個單位沒有看板／帳號**（§1 的「—」）。新增時沿用現有命名：國軍醫院用三碼數字 id，但三總本院、澎湖分院、屏東分院等的編號 repo 內查不到，不要自行編號，要等業主提供。
2. 非醫院單位（國防醫學大學、預防醫學研究所、衛勤訓練中心、三軍衛材供應處）是否契約容量 > 800 瓩、是否各自為能源用戶、是否與三總併同申報，要先確認。
3. 榮總 5 院是否納入本次三類填報（初始建檔／定期更新／異動登錄），待業主決定。
4. 工作清單寫「現有 15 個帳號」，實際是 16 個看板，`accounts.json` 也是 16 組。
5. 國軍醫院不屬 EX01「國軍部隊用戶」排除對象（業主 2026-10-22 確認），所以 §1 的醫院都要辦理。

## 2. 業務規則（系統檢核邏輯）

**R1 能源用戶判定**：契約用電容量 > 800 瓩；114–117 規定同一商工登記主體所屬電力用戶契約容量合併計算。欄位 `contract_capacity_kw`、`is_energy_user`（自動）。

**R2 排除條件**（任一符合即非能源用戶，需填理由＋佐證）

| 代碼 | 條件 |
|---|---|
| EX01 | 國軍部隊用戶 |
| EX02 | 車道及隧道用電用戶 |
| EX03 | 專供軌道車輛牽引用電用戶 |
| EX04 | 港埠裝卸作業用電用戶 |
| EX05 | 廣播電臺用電用戶 |
| EX06 | 專供營繕工程施工用電用戶 |
| EX07 | 臨時用電用戶 |
| EX08 | 依能管法第 16 條第 1 項製作能源使用說明書之新設用戶，核准日起 5 年內（填核准日→自動算到期日） |
| EX09 | 適用電動車充換電設施電價之用戶 |
| EX10 | 取得 ISO/CNS 50001 證書且每年提供有效證書（填效期→到期提醒） |
| EX11 | 其他經中央主管機關認定之用戶 |

**R3 診斷團隊資格**

| 類型 | 代碼 | 條件 |
|---|---|---|
| 法人 | Q-L1 | ≥1 名機械／冷凍空調／電機／化工技師證書全職員工，且 ≥2 名具 >5 年廠務／製程／機電／節能改善經驗＋（能管訓練合格證書或高級電氣技術人員）全職員工，其中 ≥1 名具能管證書 |
| 法人 | Q-L2 | ≥5 名上述經驗＋資格全職員工，其中 ≥3 名具能管證書 |
| 法人 | Q-L3 | 受主管機關委託提供節能減碳輔導服務 |
| 學校或機構 | Q-S1 | 受主管機關委託提供節能減碳輔導服務 |
| 執業技師 | Q-E1 | 執照科別為機械／冷凍空調／電機／化工，且提報日 ≤ 執照到期日 |

**R4 節能改善措施**：設備類別＝照明、動力、電熱、空調、冷凍冷藏、其他；改善作為＝效率提升、維護保養、更換高效率設備或零組件。

**R5 回收年限** = 投資金額 ÷ 節省能源費用（元/年）；節省費用 = 0 → 顯示「無法回收／不適用」。

**R6 必列設備汰換表**（附件一註 2）：螢光燈具 > 2 年、LED 燈具 > 8 年、公用設備 > 10 年、製程設備 > 20 年。以製造年份與提報年度算機齡，超過者強制出現在設備汰換表（不可刪，可補說明）。

**R7 節能計畫納入**：診斷報告回收年限 < 10 年之措施必列入節能計畫（自動帶入、不可刪）；未填預計完工年度 → 備註必填；預計完工年度限提報年度～提報年度+4。

**R8 計畫執行與變更**：併同附表三申報；保留計畫版本紀錄（變更前後、日期、原因）。

**R9 申報表檢核**

| 規則 | 條件 |
|---|---|
| 能管人員人數 | 契約容量 > 100,000 瓩須 ≥2 名，≥1 名自置 |
| 營業規模 | 醫院必填（床） |
| 出租率 | 僅辦公大樓必填 |
| EUI 差異 | 年增減 > 10% 須填原因 |
| 功因 | 合理值 > 95%（低於提示） |
| 變壓器負載率 | 合理 50–75%（範圍外提示） |
| 冰水機群組效率表 | 單一群組主機總容量 ≥ 1,000 冷凍噸必填 |
| ISO 50001 | 已通過 → 表四之二第 2–5 題免填 |
| PUE 表 | 僅電信／電腦機房類用戶必填 |
| 蒸汽鍋爐自我檢測 | 僅蒸汽鍋爐且非貫流式 |
| 重大使用能源設備 | 陸用燃煤／燃油／燃氣蒸汽鍋爐（不含貫流式） |

## 5. 能源查核制度申報表－附表三（非生產性質行業）

> 底稿為舊版；115/1/23 修正：改各年度通用格式，以「N」表資料年（115 年申報 114 年資料，N=114）；配合 114–117 節電規定修正。🔄＝推定已調整，需核對官方 PDF。

**5.0 前言**：>800 瓩列管，可紙本／電子檔／網路申報（網路需上傳簽名用印基本資料）；須由已設置登記之技師或能管人員填寫簽章；罰則能管法 21／23／24 條。

**5.1 一、填表人員**：是否已完成技師或能管人員設置登記（是／否）。【是】姓名、單位／職稱、設置登記核准編號、登記日期、聯絡地址、電話／分機、手機、傳真／分機、電子郵件。【否】填表人姓名等聯絡資料；未設置原因（複選：原人員離職／登記辦理中（合格證書文號）／參訓未通過／無符合資格人員／待找委託對象／本年度首次申報／不清楚規定／其他）；後續改善方式（規劃派員參訓／委託技師或合格能管人員）。

**5.2 二、其他技師或能管人員（多筆）**：姓名、單位／職稱、設置登記核准編號、登記日期、是否仍執行能源管理業務。

**5.3 三、能源用戶基本資料**：填表日期。總公司：01 名稱、02 統一編號、03 代表人、04 職稱、05 地址。能源用戶：06 用戶編號、07 用戶名稱、08 負責人、09 負責人職稱、10 統一編號、11 電號、12 能源使用地址、13 用戶連絡地址、14 行業編號及分類、15 用戶分類（醫院）、16 營業規模（床，醫院必填）、17 員工人數、18 全年工作時數、19 總樓地板面積 ㎡（附佐證）、20 總空調使用面積 ㎡、21 總室內停車場面積 ㎡、22 總能源費用 萬元/年、23 營業額 百萬元/年、24 能源費用占總支出比例 %、25 出租率 %（僅辦公大樓）。簽名用印；合併申報（多筆：序號、合併申報電號、契約容量 瓩）。

**5.4 四、能源查核組織與政策**
- 表四之一（多筆）：類別（管理／推行／執行，三階層須齊全；管理不得兼推行或執行）、姓名、職稱、實際年度工作內容。
- 表四之二：1 是否通過 ISO/CNS 50001（是→驗證機構、證書效期，免答 2–5）；2 高階主管對外發布能源政策聲明；3 定期檢討節能成效並留紀錄；4 採購優先高效率設備；5 員工或供應商節能建議溝通管道；6 是否裝設 EMIS（是→複選：電力、空調、空壓、照明、冷凍冷藏、送排風、給水污水、鍋爐、熱泵、其他）。

**5.5 五、能源使用量**
- 表五之一 熱能（1–12 月，依帳單）：燃料油 公秉、液化石油氣 公斤、天然氣 立方公尺、汽油 公升、柴油 公秉；各含總價（元含稅）；總計、平均、供應商、客戶編號。
- 表五之二 電能（每電號一張，1–12 月＋合計＋平均）：編號、電號、契約用電別、戶名、用電地址、行業別；經常契約容量（瓩）；最高需量（尖峰、半尖峰、週六半尖峰、離峰）；用電度數（尖峰、半尖峰、週六半尖峰、離峰、合計）；轉供度數、功因 %、總電費（元含稅）。
- 表五之三 單位能源使用效率因子：照明耗電功率占最高尖峰需量 %、空調占比（中央空調／其他型式）%、空調總裝置噸數 USRT、夏季最大運轉噸數 USRT。
- 表五之四 電能績效自我評比（1–12 月及全年；🔄 N-1、N）：N-1／N 年室內樓地板面積、N-1／N 年 EUI（度/㎡）、每季差異 %、原因。室內面積 = 總樓地板 − 室內停車場；差異 > 10% 須說明。
- 表五之五 熱能績效自我評比：同上，EUI 單位「公升油當量/㎡」。

**5.6 六、能源流程分析**：電能平衡圖（台電總用電度數含轉供、再生能源自用、回售台電、再生能源總發電量；依設備分類 空調、照明、冷凍冷藏、事務、送排風、給水污水、電梯、其他 → 度、%）。熱能平衡圖（燃料別熱值 百萬卡/年、%；用途：房間用、三溫暖、溫水游泳池、洗衣房、廚房餐廳、消毒設備、車輛、發電機、其他）。

**5.7 七、建築資料（多筆）**：編號、用戶分類、建築名稱（表九須一致）、建造年份（民國）、地下樓層、地上樓層、建築總樓地板面積 ㎡、屋頂構造、建築入口大門方位。

**5.8 八、電能系統**

## 6. 節電率目標與公式

| 對象 | 平均年節電率目標 |
|---|---|
| 公司全體契約容量 801～10,000 瓩 | 1% |
| > 10,000 瓩 | 1.5% |
| 國營事業 | 1.5% |

年度節電量：實施日次月起算最多 12 個月。年度用電量 = 購電 + 自發 − 售電。年度節電率 = 節電量 ÷ (節電量 + 用電量)。平均年節電率 = (累計節電量 + 前期超額節電量) ÷ (累計節電量 + 累計用電量)。每年 3/31 前申報。

換算：回收年限 = 投資 ÷ 年節省費用；EUI 電 = 年用電度數 ÷ (總樓地板 − 室內停車場)；EUI 熱 = 年熱能（公升油當量）÷ 室內面積；冰水效率 = kWh ÷ RTh；PUE = (a+b)/b；能源費用比例 = 總能源費用 ÷ 總支出；需量反應節電量 = kW × h；1 USRT = 3,024 kcal/hr；公噸油當量換算係數待取得。
